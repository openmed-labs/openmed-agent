    DOCS — PROJECT · CONTRIBUTING

    Contributing¶

    External issue intake and pull requests are currently closed during the preview period.

    Status¶

    OpenMed is not currently accepting external issues or contributions.

    Bug reports¶

    Paste the output of openmed env in your issue:

    openmed env

    Then describe:

    • Steps to reproduce — what you did, what you expected, what happened
    • Error messages — copy the full error output if available

    Feature requests¶

    • Describe the clinical or workflow use case
    • Explain what you'd like the agent to do
    • Include example prompts or expected behavior if possible

    Documentation issues¶

    Documentation feedback is being collected through direct preview channels for now.

    Feedback¶

    General feedback is being collected through direct preview channels during this period.
